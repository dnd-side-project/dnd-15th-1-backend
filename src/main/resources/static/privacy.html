제3조 (수집하는 개인정보 항목 및 수집 방법)

3.1 회원가입 및 소셜 로그인

둘픽은 Apple, Google, Kakao 소셜 로그인(OIDC 기반)을 통해 다음 정보를 처리합니다.

  • 소셜 로그인 제공자 (Apple / Google / Kakao)
  • 소셜 계정 고유 식별값
  • 이메일 (Apple 로그인 가리기 선택 시 비공개 이메일 주소 포함)
  • 이름 또는 닉네임
  • 프로필 이미지
  • 계정 생성 일시 / 최근 로그인 일시

둘픽은 사용자의 소셜 계정 비밀번호를 직접 입력받거나 저장하지 않습니다.

3.2 외부 콘텐츠 공유 및 분석

사용자가 Instagram 릴스 또는 YouTube Shorts의 "공유하기" 기능을 통해 둘픽으로 콘텐츠를 전달하면 다음 정보가 처리됩니다.

  • 원본 콘텐츠 URL
  • 콘텐츠 제공 플랫폼
  • 콘텐츠 제목 / 설명 / 해시태그 / 자막
  • 썸네일 및 영상 일부 프레임
  • 콘텐츠 공유 시각

3.3 장소 저장 및 관리

  • 장소명, 주소, 위도·경도, 장소 유형
  • 대표 이미지(썸네일), 장소 설명
  • 원본 콘텐츠 URL 및 플랫폼
  • 저장 일시, 사용자 식별값
  • 분석 결과 및 사용자가 수정한 장소 정보

3.4 커플 연결

  • 커플 연결 상태, 상대방 식별값
  • 연결 일시, 커플 연결 이력

3.5 위치정보

지도 기능 이용 시점의 현재 위치 (일시적 사용, 서버 미저장)

3.6 푸시 알림

  • FCM 등록 토큰
  • 기기 식별 기술 정보, 운영체제, 앱 버전
  • 알림 수신 설정, 알림 발송 기록

3.7 신고 및 문의

  • 신고 대상(장소/콘텐츠), 신고 사유, 신고 내용
  • 문의 내용 및 처리 결과

3.8 자동 수집 정보

  • IP 주소, 접속 일시, 서비스 이용 기록
  • 기기 모델, 운영체제, 앱 버전
  • 오류·장애 기록, 보안 관련 기록

제8조 (개인정보 국외 이전)

둘픽의 자체 서버와 로컬 AI 모델(Gemma 등)은 대한민국에서 운영됩니다.

다만 Gemini API, Firebase Cloud Messaging 등 Google 서비스 이용 과정에서 개인정보 또는 콘텐츠 정보가 국외에서 처리될 수 있습니다. 이 경우 이전되는 개인정보 항목, 국가, 목적, 이전받는 자, 보유기간 및 거부 방법을 본 방침에 고지합니다.

제9조 (인공지능 분석 시스템)

9.1 외부 AI 서비스 (Gemini API)

  • 제공자: Google
  • 목적: 콘텐츠 URL, 제목, 설명, 자막, 썸네일, 영상 프레임에서 장소 정보 추출

Gemini API 이용 시 Google에 전달되는 데이터의 범위와 보관 여부에 따라 처리위탁 및 국외 이전 내용을 본 방침에 추가로 고지합니다.

9.2 로컬 AI 모델 (Gemma 등)

  • 운영 위치: 대한민국 서울 소재 둘픽 서버
  • 목적: 콘텐츠 텍스트 분석 및 장소 정보 추출
  • 특징: 로컬 실행 모델 사용 시 분석 정보가 외부로 전달되지 않음

제10조 (위치정보)

  • 둘픽은 사용자의 개인 위치정보를 서버에 저장하지 않습니다.
  • 현재 위치는 지도 기능 이용 시점에 기기에서 조회하여 기능 제공에 필요한 범위에서만 일시적으로 사용합니다.
  • 사용자의 이동 경로를 추적하거나 위치 이력을 생성하지 않습니다.
  • 위치 권한을 허용하지 않아도 지도 기반 기능을 제외한 다른 기능 이용이 가능합니다.

제11조 (커플 연결 시 정보 공개)

커플로 연결된 상대방에게 공개되는 정보:

  • 닉네임 또는 기본 프로필
  • 상대방이 저장한 장소 및 원본 콘텐츠 링크
  • 장소 저장 일시
  • 공통 저장 장소

커플 상대방에게 공개되지 않는 정보:

  • 소셜 로그인 인증 토큰 및 사용자 식별값
  • 이메일(비공개 포함)
  • FCM 토큰, 접속 로그, 기기 정보
  • 신고·문의 내용, 계정 보안 정보

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  2. 오류 정정 요청

사용자는 둘픽 앱 내 설정에서 회원 탈퇴를 요청할 수 있습니다. 탈퇴 시:

  • 계정 비활성화 및 커플 연결 해제
  • 상대방 저장 목록 접근 차단
  • 푸시 알림 중단, 소셜 로그인 연결 해제
  • 탈퇴 후 12개월간 관련 법령에 따른 보관 후 파기
